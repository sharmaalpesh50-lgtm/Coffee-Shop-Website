# ☕ Coffee Shop Website

A modern and responsive coffee shop website built using HTML, CSS, and JavaScript.  
The website provides a clean and user-friendly interface to explore the coffee shop, menu, testimonials, and gallery.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive design
- Home page
- About section
- Coffee menu
- Customer testimonials
- Image gallery
- Responsive navigation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
